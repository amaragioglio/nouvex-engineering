What helps a design project start well.

Existing information does not need to be complete, but it should identify the function and constraints that matter.

  • Purpose, user, environment, and required function
  • Envelope, interfaces, loads, motion, and utilities
  • Materials or manufacturing constraints already known
  • Existing sketches, CAD, drawings, photographs, or reference parts
  • Prototype objective, target quantity, and timeline
